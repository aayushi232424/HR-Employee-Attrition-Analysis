# HR Employee Attrition Analysis Dashboard

## Project Overview
This project uses Power BI to analyze employee attrition patterns and identify factors associated with employee turnover. The dashboard helps users explore HR data through interactive filters and visualizations.

## Objective
To build an interactive dashboard that answers the question: **“Why are employees leaving?”**

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- IBM HR Analytics Employee Attrition Dataset

## Dashboard Features
- HR Attrition Overview
- Factors Associated with Employee Attrition
- Employee and Job Role Analysis
- Interactive filtering by department, age group, and other available employee attributes
- KPI cards and visual comparisons of attrition rates

## Key Insights
- Overall employee attrition rate: approximately 16.12%.
- Employees working overtime show a higher attrition rate than employees not working overtime.
- Younger employees, particularly those aged 18–25, show a higher attrition rate.
- Employees with shorter company tenure show higher attrition rates.

These findings indicate associations in the dataset and do not establish that any single factor causes attrition.

## Dataset
IBM HR Analytics Employee Attrition dataset: [Kaggle Dataset](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)

## Note
The dataset does not contain a Region column, so the dashboard uses available attributes such as department and age group instead.
